# Курсов проект по СПАИТ: модел на регистър

**Вариант 2 – Data Modeling**  
**Тема:** Регистър на защитените територии и защитените зони в България  
**Статус:** работна версия за допълване

## Съдържание на проекта

- `data/` — изтеглени данни от ИАОС и МОСВ: XLS категории, Shapefile за защитени територии и Shapefile за Натура 2000;
- `scripts/build_model.py` — офлайн генератор на табличния модел от данните в `data/`;
- `scripts/build_map.py` — офлайн генератор на SVG геометрията от Shapefile;
- `model/` — генерирани изходи: защитени територии, заличени територии, вековни дървета, SCI/SPA зони, карта и речник;
- `charts/` — Python скрипт, статистически изображения и машинночетим статистически файл;
- `docs/SPAIT_kursov_proekt.docx` — писмен доклад, форматиран по изискванията на заданието;
- `presentation.md` — план на слайдовете и говорни бележки за представянето;
- `model.md` — описание на избора, концептуалния модел, колоните и изводите;
- `assignment_compliance.md` — сверка на наличните материали с изискванията на заданието;
- `ЗАДАНИЕ_ФМИ_СПАИТ_2026_framework.pdf` — предоставено официално задание;
- `frontend/` — React интерфейс за търсене, филтриране, карта и преглед на записите.

## Данни и тяхното състояние

Основният изход `model/protected-areas.csv` обединява 1082 GIS записа от
`zpo_all.dbf` с данните от ИАОС по категория и пореден номер. Липсващи
стойности от регистъра остават празни; скриптът не извлича данни от интернет.

Останалите изходи разделят заличени защитени територии, вековни дървета и
двата типа Натура 2000 зони — SCI и SPA.

## Възпроизводимост

Изграждане на целия локален модел:

```powershell
python -m pip install -r requirements.txt
python .\scripts\build_model.py
python .\scripts\build_map.py
python .\charts\generate_charts.py
```

## Отворен формат и лиценз

**Формат.** Моделът е в CSV (UTF-8, RFC 4180) и GeoJSON (EPSG:4326) – отворени,
машинночетими формати, които се отварят с безплатни средства. Изходната геометрия
е в Shapefile; за работа с нея може да се ползва свободният софтуер QGIS.

**Лиценз.** Отвореният формат е техническата страна; лицензът определя правото
на повторно използване. В хранилището има три вида съдържание:

| Съдържание | Лиценз |
|---|---|
| Код (`scripts/`, `charts/*.py`, `frontend/`) | [MIT](LICENSE) |
| Модел, графики и документация (`model/`, `charts/*.png`, `docs/`) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.bg) |
| Изходни данни (`data/`) | Собственост на ИАОС/МОСВ; не са лицензирани от нас |

**Указване на източника.** При използване на модела посочете:
„Модел: екип SPAIT-proj, CC BY 4.0. Данни: Изпълнителна агенция по околна
среда (ИАОС), Регистър на защитените територии.“

Изходните данни са информация от обществения сектор и се използват повторно по
Закона за достъп до обществена информация. ИАОС не посочва изричен лиценз за
регистъра – затова в проекта предлагаме това да се уреди в Наредба № Н-3.
