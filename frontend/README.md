# Защитени територии — Explorer

React + Vite интерфейс за разглеждане на работния CSV набор.

## Стартиране

```powershell
npm install
npm run dev
```

Създаване на production build:

```powershell
npm run build
```

Данните се четат от `../../model/protected-areas.csv` чрез Vite raw import.
Търсенето работи по име, регистров номер, код и категория. Детайлният панел
показва само полетата, които присъстват в набора, и препраща към официалния
запис на ИАОС.

Площта и данните за местоположение/обявяване се показват само когато изтегленият
регистров набор има стойност за записа. Липсващите стойности остават непопълнени.

Картата се визуализира локално като SVG от `../../model/territory-map.json`.
Генерираният модел съдържа 1082 опростени контура и се
зарежда като част от Vite build-а, без отделен URL/API endpoint. При
промяна на Shapefile регенерирай картата с:

```powershell
python .\scripts\build_map.py
```

Външните картни връзки не се използват като картна услуга; детайлният панел
отваря само официалната страница на съответния запис.
