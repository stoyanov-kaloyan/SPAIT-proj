# Защитени територии — Explorer

React + Vite интерфейс за разглеждане на работния CSV набор.

## Стартиране

```powershell
npm install
npm run dev
```

Създаване на production build:

```powershell
npm run build
```

Данните се четат директно от `../protected_territories.csv` чрез Vite raw import.
Търсенето работи по име, регистров номер, код и категория. Детайлният панел
показва само полетата, които присъстват в набора, и препраща към официалния
запис/картата на ИАОС.

Площ, местоположение и правни данни не са налични в текущия CSV слой и затова
интерфейсът ги обозначава като липсващи вместо да симулира пълнота.

Картата се визуализира локално като SVG от геометриите в `../zpo_all/`.
Генерираният `public/territory-map.json` съдържа 1081 опростени контура. При
промяна на Shapefile регенерирай картата с:

```powershell
python .\scripts\build_map.py
```

Старите `MAP_URL` връзки не се използват като картна услуга; детайлният панел
отваря само официалната страница на съответния запис.
